## 🎓 LESSONS LEARNED

### Technical
1. **Adaptive personalisation requires thoughtful data modeling** — The questionnaire structure drives everything
2. **SHAP is powerful but requires careful feature engineering** — Garbage in, garbage out
3. **Real-time systems need polling or WebSockets** — We chose polling (simpler)
4. **React Query is perfect for this use case** — Automatic refetching, caching, state management
5. **Framer Motion makes everything feel premium** — Animations matter

### Process
1. **Start with backend** — Get the data model right first
2. **Build services before routes** — Business logic separate from API
3. **Seed realistic data** — Makes testing so much easier
4. **Document as you go** — Future you will thank present you
5. **Integration is separate from building** — Build components, then integrate

### Product
1. **Personalisation is the differentiator** — Generic systems are forgettable
2. **Explainability builds trust** — Clinicians need to understand the AI
3. **Cultural sensitivity is not optional** — Ghana-specific design matters
4. **Community needs moderation** — Can't be Wild West
5. **Death is part of palliative care** — Continuity Bridge is essential
