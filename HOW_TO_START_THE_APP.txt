═══════════════════════════════════════════════════════════════
  WHAT IF IT DOESN'T WORK?
═══════════════════════════════════════════════════════════════

Problem: Browser shows "Connection Refused"
Solution: Wait a bit longer (30-40 seconds) for servers to start

Problem: Port 8000 or 5173 already in use
Solution: 
  1. Run STOP_PROJECTAURA.bat first
  2. Wait 5 seconds
  3. Run START_PROJECTAURA.bat again

Problem: Backend window shows errors
Solution:
  1. Check that Python virtual environment exists
  2. Make sure you're in: c:\xampp\htdocs\ProjectAura_React
  3. Check that backend\venv folder exists

Problem: Frontend window shows errors
Solution:
  1. Make sure Node.js is installed
  2. Check that frontend\node_modules exists
  3. If not, run: cd frontend && npm install
