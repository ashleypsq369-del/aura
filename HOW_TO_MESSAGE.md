# 💬 Quick Guide: How Doctors & Patients Contact Each Other

## The Answer: **THEY CAN!** ✅

The messaging system is fully functional. Here's exactly how to use it:

---

## 🩺 For Doctors/Clinicians

### Method 1: From Messages Page (Most Common)
```
1. Click "Messages" in sidebar
2. Click the "+" button (top right)
3. Select a physician/user from the list
4. Type your message → Send
```

### Method 2: From Patient Detail Page (Quick Access)
```
1. Go to Dashboard
2. Click on any patient
3. Click the green "Message" button (top right)
4. Starts conversation automatically
```

### Method 3: From Alert Notifications
```
1. When an alert appears
2. Click on the alert
3. Message button available in alert modal
4. Quick contact for urgent situations
```

---

## 🏥 For Patients

### Method 1: From Messages Page
```
1. Click "Messages" in sidebar
2. Click the "+" button
3. You'll see list of physicians
4. Click on your doctor
5. Type your message → Send
```

### Method 2: From Patient Portal (My Space)
```
1. Go to "My Space" (your patient portal)
2. Find "Your Care Team" section
3. Click "Message" next to your clinician
4. Opens Messages page ready to chat
```

### Method 3: Existing Conversations
```
1. Go to "Messages"
2. See list of conversations on the left
3. Click on your doctor's conversation
4. Continue chatting
```

**Top Buttons:**
- **[+]** = Start new private chat
- **[👥]** = Start new group chat

## 🚨 What About Urgent Messages?

### For Critical Situations

Alert messages are sent automatically:
```
1. AI system detects critical vital signs
2. Clinician receives RED ALERT message 🚨
3. Message shows as urgent in conversation
4. Clinician can respond immediately
```

Example:
```
🚨 ALERT: Patient vitals outside normal range
   BP: 160/100, HR: 110
   [View Patient] [Respond]
```

## ❓ FAQ

### Q: Can I see if someone read my message?
**A:** Read receipts are tracked in the backend. Visual indicators coming soon.

### Q: How often do messages refresh?
**A:** Every 30 seconds automatically. New messages appear without refresh.

### Q: Can I delete a message?
**A:** Not yet implemented. Feature planned for future update.

### Q: What if I don't see any doctors to message?
**A:** 
- Ensure you're logged in
- Check your role/permissions
- Patients should see their assigned clinician
- Contact admin if issue persists

### Q: Can family members message doctors?
**A:** Yes! Family members can message the care team of linked patients.

### Q: Are messages secure?
**A:** Yes! HIPAA-compliant, role-based access control, full audit logging.

### Q: Can I attach files?
**A:** Not yet. Text only for now. File attachments planned for future.
