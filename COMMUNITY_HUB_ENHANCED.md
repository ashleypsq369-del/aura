## 💡 KEY FEATURES

### 1. **Anonymization**
- Display names hide full identity
- Example: "Kofi · Cancer Journey" instead of "Kofi Mensah"
- Protection for stigmatized conditions (HIV/AIDS)
- Safe space for vulnerable sharing

### 2. **280-Character Posts**
- Concise, focused sharing
- Easy to read and digest
- Reduces overwhelming long posts
- Encourages multiple interactions

### 3. **Emoji Reactions**
- 🙏 Pray - "Praying for you"
- ❤️ Heart - "Sending love"
- 💪 Strong - "You're strong"
- Non-verbal support that transcends language

### 4. **Moderation & Safety**
- Flag inappropriate posts
- Auto-hide posts with 5+ flags
- Moderator (admin/clinician) review
- Hidden posts visible to mods with notice

### 5. **Member Counts**
- See how many members in each group
- Encourages joining active groups
- Shows you're not alone

### 6. **Join/Leave Freely**
- One-click join/leave
- Join multiple groups
- Only members can post and see posts
- Privacy protection

## 🔐 PRIVACY & SAFETY

### Anonymization Rules

**Patient Role:**
- Format: `FirstName · ConditionType Journey`
- Example: `Kofi · Cancer Journey`
- Condition detected from diagnosis

**Family Role:**
- Format: `Family of PatientFirstName · ConditionType Journey`
- Example: `Family of Ama · Heart Disease Journey`
- Links to patient's condition

**Clinician/Caregiver:**
- Format: `Full Name (Care Team)`
- Example: `Dr. Kwame Mensah (Care Team)`
- Professional identifier

**Admin:**
- Format: `Full Name (Moderator)`
- Example: `Aura Care Team (Moderator)`
- Authority identifier

### Safety Features

1. **Content Moderation**
   - Users can flag inappropriate posts
   - Auto-hide after 5 flags
   - Moderator review queue
   - Hidden posts shown with warning to mods

2. **280-Character Limit**
   - Prevents oversharing
   - Keeps focus on support
   - Easier moderation

3. **Membership Required**
   - Must join to post and view
   - Reduces spam
   - Creates committed community

4. **No Private Messaging in Posts**
   - Contact info not allowed
   - Use Messages feature for 1-on-1
   - Keeps community public and safe

## 📊 DATABASE SCHEMA

### Tables Used
- **community_groups** - Group metadata
- **community_memberships** - User group memberships
- **community_posts** - User posts (280 chars)

### Fields
```sql
-- Groups
id, name, description, condition_tags (JSON), 
is_active, member_count, created_at

-- Memberships
id, user_id, group_id, joined_at, is_active

-- Posts
id, group_id, author_id, display_name (anonymized),
content (max 280), is_moderated, is_hidden, flag_count,
reactions (JSON: {pray, heart, strong}), created_at
```

## 🚀 TECHNICAL IMPLEMENTATION

### Backend (`backend/routers/community.py`)
- **GET /api/community/groups** - List all groups
- **POST /api/community/groups/{id}/join** - Toggle membership
- **GET /api/community/groups/{id}/posts** - Get posts
- **POST /api/community/posts** - Create post
- **POST /api/community/posts/{id}/react** - Add reaction
- **POST /api/community/posts/{id}/flag** - Flag post
- **PUT /api/community/posts/{id}/moderate** - Moderate (admin only)

### Frontend (`frontend/src/pages/CommunityHub.jsx`)
- React Query for data fetching
- Framer Motion for animations
- Modern card-based layout
- Emoji reactions with hover effects
- Real-time updates via polling
- Responsive grid layout

### Seeding (`backend/seed_community_groups.py`)
- Creates 50 groups in 10 categories
- Adds 8 welcome posts
- Sets proper member counts
- Initializes reaction counts
