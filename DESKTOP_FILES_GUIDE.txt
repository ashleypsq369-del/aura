═══════════════════════════════════════════════════════════════
  🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "Connection Refused" in browser
Solution: Wait longer (give it 40 seconds instead of 30)

Problem: Batch file doesn't work
Solution: Right-click → "Run as Administrator"

Problem: Port already in use
Solution: 
  1. Run STOP_PROJECTAURA.bat
  2. Wait 10 seconds
  3. Run START_PROJECTAURA.bat again

Problem: Can't find minimized windows
Solution: Look in taskbar for "ProjectAura-Backend" 
          and "ProjectAura-Frontend"
