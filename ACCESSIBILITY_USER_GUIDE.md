## 📖 Quick Start Guide

### Finding the Accessibility Settings

Look for the **⚙️ Settings button** in the bottom-right corner of your screen.
- It's always visible on every page
- Click it to open the accessibility settings panel

## 👥 Guides by User Type

### 🦯 For Blind Users (Screen Reader Users)

#### What is a Screen Reader?
A screen reader is software that reads the screen aloud to you. Popular options:
- **NVDA** (Windows) - Free: https://www.nvaccess.org/download/
- **JAWS** (Windows) - Commercial
- **VoiceOver** (Mac) - Built-in (press Cmd + F5 to enable)

#### How to Use ProjectAura with a Screen Reader

**Step 1: Enable Your Screen Reader**
- NVDA: Open NVDA software
- JAWS: Open JAWS software  
- VoiceOver: Press `Cmd + F5` (Mac)

**Step 2: Open Accessibility Settings**
1. Press `Tab` until you reach the "Open accessibility settings" button
2. Press `Enter` or `Space` to open
3. Tab to "Screen Reader Optimizations"
4. Press `Space` to turn it ON

**Step 3: Navigate the Site**
- Use `Tab` to move between interactive elements
- Use heading navigation (`H` key in NVDA/JAWS)
- Use landmark navigation (`D` key for main regions)
- All buttons and links will be read aloud with descriptions

**Helpful Keyboard Shortcuts:**
- `Alt + 1` = Jump to main content
- `Alt + 2` = Jump to navigation
- `Alt + H` = Go to home page
- `Tab` = Next element
- `Shift + Tab` = Previous element
- `Esc` = Close dialog boxes

### 👀 For Low Vision Users

#### Making Text Easier to Read

**Step 1: Open Accessibility Settings**
- Click the ⚙️ Settings button (bottom-right)

**Step 2: Enable High Contrast**
- Toggle "High Contrast Mode" ON
- Text becomes black on white background
- All borders become bold and clear

**Step 3: Increase Font Size**
- Choose from 5 sizes:
  - **Small** (14px) - Compact
  - **Medium** (16px) - Standard
  - **Large** (18px) - Comfortable ✓ Recommended
  - **Extra Large** (20px) - Big text
  - **XXL** (24px) - Maximum size

**Step 4: Use Browser Zoom**
- Press `Ctrl` and `+` to zoom in
- Press `Ctrl` and `-` to zoom out
- Press `Ctrl` and `0` to reset zoom
- Our app supports up to **400% zoom** without breaking!

#### Additional Tips
- **Large Touch Targets:** Enable this to make all buttons bigger
- **Simplified Interface:** Removes visual clutter for easier focus

### 🎤 For Bedridden/Motor-Impaired Users (Voice Control)

#### Hands-Free Navigation with Your Voice

**What Can Voice Control Do?**
- Navigate to any page by speaking
- Save forms by saying "save"
- Scroll pages by voice
- Close dialogs by saying "cancel"
- **No keyboard or mouse needed!**

#### Setting Up Voice Control

**Step 1: Open Accessibility Settings**
- Ask someone to help click the ⚙️ Settings button (bottom-right)
- OR use keyboard: Press `Tab` until you reach it, then press `Enter`

**Step 2: Enable Voice Control**
1. Find "Voice Control" toggle
2. Turn it ON
3. Your browser will ask for microphone permission - click "Allow"
4. You'll hear: "Voice control activated"

**Step 3: Start Speaking Commands**

**Navigation Commands (Say These):**
- "Go home" - Go to homepage
- "Dashboard" - Go to dashboard
- "Go to patients" - See patient list
- "Go to messages" - Check messages
- "Go to alerts" - See alerts
- "Go to medications" - View medications
- "Go to journal" - Open your journal
- "Go to community" - Visit community
- "Go to profile" - View your profile

**Action Commands:**
- "Save" or "Save form" - Save current form
- "Cancel" - Cancel or close current dialog
- "Go back" - Go to previous page
- "Refresh" - Reload the page
- "Scroll down" - Scroll page down
- "Scroll up" - Scroll page up
- "Top" - Scroll to top of page
- "Bottom" - Scroll to bottom of page

**Help Commands:**
- "Help" - Hear list of available commands
- "List pages" - Hear all pages you can visit

**Tips for Best Results:**
- Speak clearly and naturally
- Wait for voice feedback after each command
- If command not recognized, try saying it differently
- Say "Help" if you forget commands

### ⌨️ For Keyboard-Only Users

#### Navigate Without a Mouse

**Step 1: Enable Keyboard Navigation Mode**
1. Press `Tab` until you reach ⚙️ Settings button
2. Press `Enter` to open
3. Tab to "Keyboard Navigation Mode"
4. Press `Space` to turn it ON

**Keyboard Shortcuts:**

**Skip Navigation (Fast Jumping):**
- `Alt + 1` = Jump to main content
- `Alt + 2` = Jump to navigation menu
- `Alt + 3` = Jump to search
- `Alt + H` = Go to home
- `Alt + M` = Go to messages
- `Alt + P` = Go to patients
- `Alt + A` = Go to alerts

**General Navigation:**
- `Tab` = Move to next button/link/field
- `Shift + Tab` = Move to previous item
- `Enter` = Click button or follow link
- `Space` = Toggle checkbox/switch
- `Arrow Keys` = Navigate within menus/lists
- `Esc` = Close dialog/modal

**Form Navigation:**
- `Tab` = Move to next field
- `Shift + Tab` = Previous field
- `Space` = Check/uncheck checkbox
- `Arrow Keys` = Select from dropdown
- `Enter` = Submit form

**Tips:**
- Blue outline shows where you are (focus indicator)
- All features accessible via keyboard
- No mouse needed at all!

### 👆 For Users with Limited Hand Mobility

#### Bigger Buttons & Touch Targets

**Step 1: Open Accessibility Settings**
- Tap the ⚙️ Settings button (bottom-right)

**Step 2: Enable Large Touch Targets**
- Toggle "Large Touch Targets" ON
- All buttons become bigger (44x44 pixels minimum)
- Easier to tap without precision

**Step 3: Optional - Enable Voice Control**
- If tapping is difficult, enable "Voice Control"
- Navigate hands-free with your voice

### 🧠 For Users with Cognitive Disabilities

#### Simplified, Cleaner Interface

**Step 1: Open Accessibility Settings**
- Click the ⚙️ Settings button (bottom-right)

**Step 2: Enable Simplified Interface**
- Toggle "Simplified Interface" ON
- Removes:
  - Complex backgrounds
  - Decorative elements
  - Visual clutter
- Result: Clean, minimal, easy-to-focus interface

**Step 3: Reduce Motion (Optional)**
- If animations are distracting:
- Toggle "Reduce Motion" ON
- All animations stop

## 🔧 Troubleshooting

### Voice Control Not Working

**Problem:** Commands not recognized

**Solutions:**
1. Check microphone permissions:
   - Chrome: Click 🔒 lock icon in address bar
   - Enable microphone access
2. Speak clearly and wait for feedback
3. Try different command phrasing
4. Say "Help" to hear available commands
5. Works best in Chrome/Edge browsers

**Problem:** "Voice control not supported"

**Solution:** Your browser doesn't support voice control. Try:
- Chrome (best support)
- Edge (best support)
- Safari (good support)
- Update your browser to latest version

---

### Screen Reader Not Reading Properly

**Problem:** Screen reader silent or skipping content

**Solutions:**
1. Ensure screen reader is running (NVDA, JAWS, VoiceOver)
2. Enable "Screen Reader Optimizations" in settings
3. Try refreshing the page (`Ctrl + R`)
4. Check screen reader is focused on browser window
5. Try landmark navigation (`D` key to jump to regions)

---

### Keyboard Shortcuts Not Working

**Problem:** Shortcuts like Alt+1 not working

**Solutions:**
1. Enable "Keyboard Navigation Mode" in settings
2. Ensure you're not in a text field (press `Esc` first)
3. Try pressing `Alt` key firmly
4. Check browser isn't blocking shortcuts
5. Some keyboards: try `Alt + Fn + 1`

---

### Text Too Small Even at Maximum Size

**Solutions:**
1. Set font size to "XXL" in settings
2. Use browser zoom:
   - `Ctrl + +` (zoom in)
   - `Ctrl + -` (zoom out)
3. Use system zoom:
   - Windows: `Windows + +` (Magnifier)
   - Mac: `Cmd + Option + 8` (Zoom)
