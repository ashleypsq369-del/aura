## 🐛 Troubleshooting

### **Problem**: "Node.js not found"
**Solution**: Install Node.js from https://nodejs.org

### **Problem**: "Python not found"
**Solution**: Install Python from https://python.org

### **Problem**: "Port 8000 already in use"
**Solution**: 
```bash
# Find what's using port 8000
netstat -ano | findstr :8000

# Kill the process
taskkill /PID [PID_NUMBER] /F
```

### **Problem**: ACE window closes immediately
**Solution**: Run from Command Prompt to see errors:
```bash
cd Desktop
ace.exe
```

### **Problem**: Browser doesn't open
**Solution**: 
- Wait 15 seconds
- Manually open: http://localhost:5173

### **Problem**: Can't find ace.exe on desktop
**Solution**: Check these locations:
- `C:\Users\User\Desktop\ace.exe`
- `c:\xampp\htdocs\ProjectAura_React\ace.exe`
