## 💡 USAGE SCENARIOS

### **Scenario 1: Patient Wants to Chat**
```
Patient clicks: 🔵 Blue ChatBot button
Patient types: "I'm feeling anxious about my treatment"
ChatBot: Provides emotional support
Patient continues: Multiple messages back and forth
Patient closes chat
Next day: Opens chat again
Result: ✅ All conversation history saved!
```

### **Scenario 2: Clinician Needs Patient Data**
```
Clinician clicks: 🟢 Teal AI Assistant button
Clinician clicks: [📋 Patients] button
AI Assistant shows: Complete patient list with vitals
Clinician clicks: [❤️ Vitals] button
AI Assistant shows: Latest vital signs
Result: ✅ Quick data access, no conversation saved
```

### **Scenario 3: User Wants Navigation**
```
User clicks: 🟢 Teal AI Assistant button
User types: "Take me to memory vault"
AI Assistant shows: Page description + [Go to Page] button
User clicks: Button
Result: ✅ Navigated to Memory Vault, chat closes
```

### **Scenario 4: Patient Wants to Save Conversation**
```
Patient clicks: 🔵 Blue ChatBot button
Patient has long conversation about care
Patient clicks: Download icon
Result: ✅ Conversation saved as text file
Patient clicks: Delete icon
Result: ✅ Conversation removed from history
```

## 🎨 COLOR PSYCHOLOGY

### **Why Blue for ChatBot?**
- 💙 **Calming** - Reduces anxiety
- 💙 **Trust** - Professional and reliable
- 💙 **Friendly** - Approachable for patients
- 💙 **Personal** - Emotional connection

### **Why Teal for AI Assistant?**
- 💚 **Medical** - Associated with healthcare
- 💚 **Clarity** - Clear purpose (clinical)
- 💚 **Focus** - Task-oriented
- 💚 **Professional** - For staff use

## ⌨️ KEYBOARD SHORTCUTS

### **ChatBot:**
- `Enter` - Send message
- `Shift + Enter` - New line in message
- `Esc` - Close chat (when input empty)
- `Ctrl/Cmd + Click` conversation - Open in new (future feature)

### **AI Assistant:**
- `Enter` - Send message
- `Esc` - Close assistant
- `Ctrl/Cmd + K` - Open assistant (future feature)
