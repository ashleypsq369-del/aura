═══════════════════════════════════════════════════════════════
  IF START_ALL.bat DOESN'T WORK
═══════════════════════════════════════════════════════════════

1. Look for minimized windows in taskbar:
   - ProjectAura-Backend
   - ProjectAura-Frontend

2. Click on them to see errors

3. Common issues:

   ❌ "venv is not recognized"
      → Virtual environment missing
      → Run: cd backend && python -m venv venv

   ❌ "No module named..."
      → Dependencies not installed
      → Run: cd backend && venv\Scripts\activate && pip install -r requirements.txt

   ❌ "npm is not recognized"
      → Node.js not installed
      → Install from: https://nodejs.org/

4. Still stuck? Use Start_Backend_MANUAL.bat to see exact error
