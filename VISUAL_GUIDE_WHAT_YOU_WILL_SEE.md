- 🟢 **Green** = Good / Available / Normal (bg-green-100, text-green-700)
- 🟡 **Yellow** = Warning / Full / Moderate (bg-yellow-100, text-yellow-700)
- 🔴 **Red** = Critical / Overloaded / Urgent (bg-red-100, text-red-700)
- 💜 **Purple** = AI Features (bg-purple-50, text-purple-700)

**Primary Colors:**
- **Teal** = Headers, buttons, links (from-teal-600 to-cyan-600)
- **Slate** = Text, borders (text-slate-900, border-slate-200)
- **White** = Cards, backgrounds (bg-white)

**Borders:**
- **3px borders** throughout (medical design standard)
- Color-coded by status
