## 🐛 TROUBLESHOOTING

**Problem:** Settings don't save
- **Solution:** Check browser localStorage is enabled

**Problem:** Can't drag buttons
- **Solution:** Click and HOLD for drag (5px threshold)

**Problem:** Theme doesn't change
- **Solution:** Hard refresh (Ctrl+Shift+R)

**Problem:** AI not navigating
- **Solution:** Check "Auto-Navigate" in Settings → AI Tools

## 🎯 COMMON TASKS

### **Change Theme to Dark:**
1. Click avatar + ⚙️
2. Click "Settings"
3. Click "Appearance" tab
4. Select "🌙 Dark Mode"
5. ✅ Entire app turns dark!

### **Increase Font Size:**
1. Go to Settings → Accessibility
2. Find "Vision & Display" section (blue)
3. Select "Extra Large (20px)"
4. ✅ Text gets bigger everywhere!

### **Enable Auto-Navigate:**
1. Go to Settings → AI Tools
2. Find "AI Assistant Settings" (teal box)
3. Toggle ON "Auto-Navigate"
4. ✅ AI now navigates automatically!

### **Disable Thinking Animation:**
1. Go to Settings → AI Tools
2. Toggle OFF "Show Thinking Process"
3. ✅ AI responds instantly!
