═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING LOGIN ERRORS
═══════════════════════════════════════════════════════════════

❌ Error: "Invalid credentials"
   → Check username/password (case-sensitive)
   → Make sure Backend is running (check terminal)

❌ Error: "Network Error" or "Cannot connect"
   → Backend not running
   → Check Backend terminal for errors
   → Restart with Start_ProjectAura.bat

❌ Error: "Database error"
   → Close backend
   → Run: cd backend && python seed_database.py
   → Restart with Start_ProjectAura.bat

❌ Blank screen after login
   → Check browser console (F12)
   → Check Frontend terminal for errors
   → Clear browser cache and refresh


═══════════════════════════════════════════════════════════════
  RESETTING THE DATABASE
═══════════════════════════════════════════════════════════════

If you want to start fresh:

1. Close Backend + Frontend (Stop_ProjectAura.bat)
2. Delete aura.db file
3. Run: cd backend && python seed_database.py
4. Start again: Start_ProjectAura.bat

All demo data will be recreated!
