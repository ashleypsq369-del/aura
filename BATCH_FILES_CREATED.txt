═══════════════════════════════════════════════════════════════
  HOW THE START BATCH FILE WORKS
═══════════════════════════════════════════════════════════════

When you double-click START_PROJECTAURA.bat:

1. Changes to project directory
   → c:\xampp\htdocs\ProjectAura_React

2. Checks if database exists
   → Confirms aura.db is present

3. Starts Backend in minimized window
   → Activates Python venv
   → Runs: python -m uvicorn main:app --reload --port 8000
   → Window title: "ProjectAura-Backend"
   → State: Minimized (runs in background)

4. Waits 15 seconds
   → Allows backend to fully initialize
   → Database loads, routes register

5. Starts Frontend in minimized window
   → Runs: npm run dev
   → Window title: "ProjectAura-Frontend"
   → State: Minimized (runs in background)

6. Waits 15 seconds
   → Allows Vite to build
   → Frontend compilation completes

7. Opens browser automatically
   → URL: http://localhost:5173
   → Shows login page

8. Shows success message
   → Displays URLs and credentials
   → Instructions for stopping

9. Closes startup window after 10 seconds
   → Main startup window auto-closes
   → Two minimized windows keep running


═══════════════════════════════════════════════════════════════
  HOW THE STOP BATCH FILE WORKS
═══════════════════════════════════════════════════════════════

When you double-click STOP_PROJECTAURA.bat:

1. Finds Backend window
   → Searches for window: "ProjectAura-Backend"
   → Kills the process forcefully
   → Confirms: "Backend stopped"

2. Finds Frontend window
   → Searches for window: "ProjectAura-Frontend"
   → Kills the process forcefully
   → Confirms: "Frontend stopped"

3. Shows success message
   → "All services shut down"
   → Window auto-closes after 5 seconds
