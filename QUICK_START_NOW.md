## 🐛 If Something Goes Wrong

### Frontend won't start?
```bash
cd c:\xampp\htdocs\HCARE\frontend
npm install --force
npm run dev
```

### Can't login?
- Check backend is running (it is!)
- Try: clinician / clinician123
- Check browser console (F12)

### Blank page?
- Refresh browser (F5)
- Check both terminals are running
- Clear browser cache
