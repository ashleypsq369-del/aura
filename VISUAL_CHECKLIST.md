# Visual Design Checklist ✅

Quick checklist to verify modern design is correctly applied.

---

## 🎨 Visual Elements Checklist

### Every Page Should Have:

#### Headers
- [ ] Gradient background (teal-600 to cyan-600)
- [ ] Rounded corners (rounded-2xl)
- [ ] Deep shadow (shadow-xl)
- [ ] Border (border-2 border-teal-400)
- [ ] Large text (text-4xl)
- [ ] White text on gradient
- [ ] Icon with proper size (w-10 h-10)

#### Cards
- [ ] White background (bg-white)
- [ ] 2px border (border-2 border-slate-200)
- [ ] Modern shadow (shadow-lg)
- [ ] Rounded corners (rounded-2xl)
- [ ] Proper padding (p-6 or p-8)
- [ ] Hover effects (hover:shadow-xl hover:scale-[1.02])
- [ ] Smooth transitions (transition-all duration-300)

#### Buttons
- [ ] Primary: Gradient (from-teal-500 to-cyan-600)
- [ ] Border (border-2 border-teal-500)
- [ ] Shadow (shadow-lg)
- [ ] Rounded (rounded-xl)
- [ ] Bold text (font-bold)
- [ ] Hover effect (hover:shadow-xl)
- [ ] Padding (px-6 py-3 or larger)

#### Form Inputs
- [ ] 2px border (border-2 border-slate-300)
- [ ] Rounded (rounded-xl)
- [ ] Shadow (shadow-md)
- [ ] Focus ring (focus:ring-4 focus:ring-teal-500/20)
- [ ] Proper padding (px-5 py-3)
- [ ] Medium font weight (font-medium)
- [ ] Placeholder color (placeholder-slate-400)

#### Tables
- [ ] White background with border-2
- [ ] Gradient header (from-slate-50 to-slate-100)
- [ ] Bold column headers (font-bold uppercase)
- [ ] Row borders (divide-y-2 divide-slate-100)
- [ ] Hover states (hover:bg-teal-50)
- [ ] Left border on hover (hover:border-teal-500)

#### Badges
- [ ] Rounded full (rounded-full)
- [ ] 2px border (border-2)
- [ ] Bold text (font-bold)
- [ ] Proper padding (px-4 py-2)
- [ ] Color-coded (bg-*-100 text-*-700 border-*-300)

#### Empty States
- [ ] Large icon (w-20 h-20)
- [ ] Muted color (text-slate-300)
- [ ] Bold heading (text-2xl font-semibold)
- [ ] Descriptive text (text-lg)
- [ ] Proper padding (p-16)

## 🎯 Color Usage Checklist

### Primary Colors (Should See)
- [ ] Teal-600 in headers
- [ ] Cyan-600 in gradients
- [ ] Teal-500 in buttons
- [ ] Teal-400 in borders

### Neutral Colors (Should See)
- [ ] Slate-900 for primary text
- [ ] Slate-600 for secondary text
- [ ] Slate-500 for muted text
- [ ] Slate-200 for card borders
- [ ] Slate-300 for input borders

### Background Colors (Should NOT See)
- [ ] ❌ Plain white page backgrounds
- [ ] ❌ No gradients on cards
- [ ] ❌ Thin 1px borders

---

## 📐 Spacing Checklist

### Standard Spacing (Should Use)
- [ ] Page padding: `p-6`
- [ ] Card padding: `p-6` or `p-8`
- [ ] Button padding: `px-6 py-3` or `px-6 py-4`
- [ ] Input padding: `px-5 py-3`
- [ ] Gap between items: `gap-6`
- [ ] Margin bottom: `mb-6` or `mb-8`

---

## 🎭 Animation Checklist

### Required Animations
- [ ] Card hover: scale and shadow increase
- [ ] Button hover: shadow increase
- [ ] Table row hover: background color change
- [ ] All transitions: `transition-all duration-300`
- [ ] Framer Motion on page load (fade in + slide up)

## 🚫 Common Mistakes to Avoid

### DON'T
- ❌ Use border (1px) - Always use border-2
- ❌ Use rounded-lg - Use rounded-xl or rounded-2xl
- ❌ Forget hover effects on interactive elements
- ❌ Use plain white page backgrounds
- ❌ Skip transitions
- ❌ Use thin shadows (shadow-sm)
- ❌ Forget to add emojis/icons where appropriate

### DO
- ✅ Use border-2 everywhere
- ✅ Use rounded-xl or rounded-2xl
- ✅ Add hover:shadow-xl on cards
- ✅ Use gradients for headers
- ✅ Add transition-all
- ✅ Use shadow-lg or shadow-xl
- ✅ Include icons in headers

## 🎯 Quick Visual Test

Open each page and verify:
1. **Header has gradient background** (teal to cyan)
2. **All cards have visible 2px borders** (not 1px!)
3. **No plain white backgrounds** (should see gradients)
4. **Shadows are visible** (cards have depth)
5. **Hover effects work** (cards lift, shadows grow)
6. **Buttons have gradients** (teal to cyan)
7. **Forms have 2px borders** (inputs clearly defined)
8. **Everything is rounded** (no sharp corners)

## ✨ Quality Standards

### Minimum Requirements
- Border width: 2px minimum
- Shadow: shadow-lg minimum
- Rounded: rounded-xl minimum
- Padding: p-6 minimum for cards
- Gradient: Required on headers
- Hover: Required on all interactive elements

### Excellence Requirements
- All borders clearly visible
- Consistent color usage
- Smooth animations
- Professional appearance
- Healthcare-appropriate design
