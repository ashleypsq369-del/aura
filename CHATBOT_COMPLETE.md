## 🔧 TECHNICAL IMPLEMENTATION

### **ChatBot Technical Stack:**
- **React Hooks:** useState, useRef, useEffect
- **Storage:** localStorage (key: 'chatbot_conversations')
- **API:** chatbotAPI.chat() from '../api/client'
- **Animation:** framer-motion (AnimatePresence, motion.div)
- **Icons:** lucide-react (MessageCircle, X, Send, Trash2, Plus, Clock, Download, Maximize2, Minimize2, ChevronDown)
- **Auth:** useAuth() context
- **Routing:** None (stays on current page)

### **AI Assistant Technical Stack:**
- **React Hooks:** useState, useRef, useEffect
- **Storage:** None (session-based)
- **API:** chatbotAPI.chat() from '../api/client'
- **Animation:** framer-motion
- **Icons:** lucide-react (MessageCircle, X, Send, Loader, ExternalLink)
- **Auth:** useAuth() context
- **Routing:** useNavigate() for page navigation

### **Key Code Patterns:**

**Auto-Focus:**
```javascript
useEffect(() => {
  if (isOpen && !loading) {
    inputRef.current?.focus();
  }
}, [isOpen, loading, messages]);
```

**Keyboard Handling:**
```javascript
const handleKeyPress = (e) => {
  if (e.key === 'Enter' && !e.shiftKey) {
    e.preventDefault();
    sendMessage();
  }
};
```

**Conversation Management:**
```javascript
// Save to localStorage
localStorage.setItem('chatbot_conversations', JSON.stringify(conversations));

// Load from localStorage
const saved = localStorage.getItem('chatbot_conversations');
const parsed = JSON.parse(saved);
```
