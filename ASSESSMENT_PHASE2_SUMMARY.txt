1. BARTHEL INDEX (/assessments/1/barthel)
   ═══════════════════════════════════════
   
   PURPOSE: Activities of Daily Living (ADL)
   
   FEATURES:
   • 10 ADL items (feeding, bathing, grooming, etc.)
   • Button-based selection (not sliders)
   • Scores 0-100
   • Shows independence level
   • Cyan/teal gradient design
   
   SCORES:
   • 90-100: Independent
   • 60-89: Slightly Dependent
   • 40-59: Moderately Dependent
   • 20-39: Severely Dependent
   • 0-19: Totally Dependent
   
   ALERTS:
   • <20 → HIGH (severe dependence)
   • <40 → MEDIUM (moderate dependence)
   • ≥20 point drop → HIGH (functional decline)


2. COGNITIVE ASSESSMENT (/assessments/1/cognitive)
   ═══════════════════════════════════════════════
   
   PURPOSE: Memory & Cognitive Function
   
   FEATURES:
   • Dual test support (MMSE or MoCA)
   • Test type selector
   • 7 components each
   • Scores 0-30
   • Automatic MoCA +1 adjustment (if education ≤12 years)
   • Purple/indigo gradient design
   
   MMSE SCORES:
   • 24-30: Normal
   • 18-23: Mild Impairment
   • 10-17: Moderate Impairment
   • 0-9: Severe Impairment
   
   MoCA SCORES:
   • 26-30: Normal
   • 18-25: Mild Cognitive Impairment
   • 10-17: Moderate Impairment
   • 0-9: Severe Impairment
   
   ALERTS:
   • <10 → CRITICAL (severe - urgent referral)
   • <18 → HIGH (moderate - evaluation)
   • <24/26 → MEDIUM (mild - monitor)


3. BRIEF PAIN INVENTORY (/assessments/1/pain)
   ═══════════════════════════════════════════
   
   PURPOSE: Comprehensive Pain Evaluation
   
   FEATURES:
   • 4 pain severity sliders (worst, least, avg, current)
   • Pain location text input
   • 14 pain type multi-select
   • 7 pain interference sliders
   • Medication tracking
   • Effectiveness slider (0-100%)
   • Red/rose gradient design
   
   PAIN INTERFERENCE:
   • General Activity, Mood, Walking
   • Work, Relations, Sleep, Enjoyment
   • Average calculated automatically
   
   INTERFERENCE LEVELS:
   • 7-10: Severe Interference
   • 5-6.9: Moderate Interference
   • 3-4.9: Mild Interference
   • 0-2.9: Minimal Interference
   
   ALERTS:
   • Worst ≥8 → CRITICAL (severe pain)
   • Average ≥7 → HIGH (high pain)
   • Interference ≥7 → HIGH (severe interference)
   • Effectiveness <30% → HIGH (ineffective meds)
