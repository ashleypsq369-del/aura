## 🐛 If Something Looks Off

### Common Issues
1. **No gradient headers?**
   - Hard refresh: Ctrl+Shift+R
   - Clear cache

2. **Borders not showing?**
   - Check browser zoom (should be 100%)
   - Try different browser

3. **Styles not applied?**
   - Restart frontend server
   - Clear browser cache

## 📞 Quick Help

### Servers Not Running?
Run these commands:

**Backend:**
```bash
cd backend
uvicorn main:app --reload
```

**Frontend:**
```bash
cd frontend
npm run dev
```

### Need to Restart?
1. Stop servers (Ctrl+C)
2. Run commands above
3. Wait for "ready" message
4. Refresh browser
