Error: Failed to load resource: net::ERR_CONNECTION_REFUSED

This means the backend server on port 8000 is not running.


═══════════════════════════════════════════════════════════════
  SOLUTION 1: Manual Start (Easiest)
═══════════════════════════════════════════════════════════════

Do these steps IN ORDER:

STEP 1: Start Backend
  1. Go to project folder
  2. Double-click "Start_Backend_MANUAL.bat"
  3. Wait for: "Uvicorn running on http://127.0.0.1:8000"
  4. Keep this window OPEN!

STEP 2: Start Frontend
  1. Double-click "Start_Frontend_MANUAL.bat"
  2. Wait for: "Local: http://localhost:5173"
  3. Keep this window OPEN!

STEP 3: Login
  1. Browser opens automatically
  2. Login with: clinician / clinician123
  3. Should work now! ✅


═══════════════════════════════════════════════════════════════
  SOLUTION 2: Check Backend Window
═══════════════════════════════════════════════════════════════

If you used Start_ProjectAura.bat:

1. Find the window titled "ProjectAura Backend"
2. Look for errors (red text)

Common errors:

❌ "ModuleNotFoundError" or "No module named..."
   → Dependencies not installed
   → FIX: See "Install Dependencies" below

❌ "venv is not recognized"
   → Virtual environment issue
   → FIX: See "Recreate Virtual Environment" below

❌ Window closes immediately
   → Python error or venv issue
   → FIX: Use Start_Backend_MANUAL.bat to see error


═══════════════════════════════════════════════════════════════
  SOLUTION 3: Install Dependencies (If Missing)
═══════════════════════════════════════════════════════════════

Open Command Prompt in project folder:

cd c:\xampp\htdocs\ProjectAura_React\backend
venv\Scripts\activate
pip install -r requirements.txt

Then try starting again.


═══════════════════════════════════════════════════════════════
  SOLUTION 4: Recreate Virtual Environment
═══════════════════════════════════════════════════════════════

If virtual environment is corrupted:

cd c:\xampp\htdocs\ProjectAura_React\backend
rmdir /s /q venv
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

Then try starting again.


═══════════════════════════════════════════════════════════════
  SOLUTION 5: Check if Port 8000 is Busy
═══════════════════════════════════════════════════════════════

Check if something else is using port 8000:

netstat -ano | find "8000"

If you see a result:
  - Another process is using port 8000
  - Close it or kill the process
  - Or change backend port in main.py
