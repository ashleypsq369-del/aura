═══════════════════════════════════════════════════════════════

The chatbot currently runs in "fallback mode" (basic responses).
For full AI conversational intelligence, add your API key:

STEP 1: Get API Key
-------------------
1. Go to: https://console.anthropic.com/
2. Create account (if needed)
3. Navigate to API Keys section
4. Generate new key
5. Copy the key

STEP 2: Add to .env File
-------------------------
File: backend\.env

Change this line:
  ANTHROPIC_API_KEY=

To this:
  ANTHROPIC_API_KEY=sk-ant-your-actual-key-here

STEP 3: Restart Backend
------------------------
Run STOP_PROJECTAURA.bat then START_PROJECTAURA.bat

COST: ~$0.001 per conversation (very affordable)
