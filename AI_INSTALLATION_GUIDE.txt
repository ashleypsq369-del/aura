STEP 1: Verify Installation
----------------------------
Open Command Prompt and run:
  cd c:\xampp\htdocs\ProjectAura_React\backend
  venv\Scripts\activate
  pip list | findstr /I "joblib xgboost shap anthropic"

You should see all 4 packages listed.


STEP 2: Re-enable AI Routers in main.py
----------------------------------------
The AI routers are currently commented out. Uncomment them:

File: backend\main.py

Change this:
  # ai,  # Requires joblib, xgboost
  # ai_analysis,  # Requires joblib, xgboost
  # intelligent_care,  # Requires joblib, xgboost
  # caregiver_intelligence,  # Requires AI packages
  # chatbot,  # Requires anthropic API

To this:
  ai,
  ai_analysis,
  intelligent_care,
  caregiver_intelligence,
  chatbot,

Also uncomment the router includes (around line 70):
  app.include_router(ai.router, prefix="/api/ai", tags=["ai"])
  app.include_router(ai_analysis.router, prefix="/api/ai-analysis", tags=["ai-analysis"])
  app.include_router(intelligent_care.router, prefix="/api/intelligent-care", tags=["intelligent-care"])
  app.include_router(caregiver_intelligence.router)
  app.include_router(chatbot.router, prefix="/api/chatbot", tags=["chatbot"])


STEP 3: Set Up Anthropic API Key (for Chatbot)
-----------------------------------------------
AuraChat chatbot requires Claude API access.

1. Get API key from: https://console.anthropic.com/
   (You'll need to create an account)

2. Create .env file in backend folder:
   File: backend\.env
   
   Add this line:
   ANTHROPIC_API_KEY=your_api_key_here

3. The backend will automatically load this key


STEP 4: Train the ML Models (First Time Only)
----------------------------------------------
The risk prediction models need to be trained with data.

Run this once:
  cd c:\xampp\htdocs\ProjectAura_React\backend
  venv\Scripts\activate
  python train_models.py

This creates the trained model files that the AI uses.


STEP 5: Restart Backend
------------------------
Option A (Using Batch File):
  1. Run STOP_PROJECTAURA.bat (on Desktop)
  2. Wait 5 seconds
  3. Run START_PROJECTAURA.bat (on Desktop)

Option B (Manual):
  1. Close backend CMD window
  2. cd c:\xampp\htdocs\ProjectAura_React\backend
  3. venv\Scripts\activate
  4. python -m uvicorn main:app --reload --port 8000


STEP 6: Test AI Features
-------------------------
After restart, test these features:

1. **AI Risk Prediction**

   - Look for chat icon

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Installation failed/timed out
Solution: Run installation again:
  cd c:\xampp\htdocs\ProjectAura_React\backend
  venv\Scripts\activate
  pip install joblib scikit-learn xgboost shap anthropic

Problem: Backend won't start after re-enabling AI
Solution: Check for missing packages:
  pip list | findstr /I "joblib xgboost shap"
  
Problem: Chatbot not working
Solution: 
  1. Check if ANTHROPIC_API_KEY is set in .env
  2. Verify API key is valid
  3. Check backend logs for errors

Problem: Risk predictions showing errors
Solution:
  1. Run train_models.py to create model files
  2. Check if models/ directory exists
  3. Verify patient data exists in database
