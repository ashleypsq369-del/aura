═══════════════════════════════════════════════════════════════
  🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: No AI predictions showing
Solution:
  - Check backend logs (minimized window)
  - Ensure ML models loaded (look for "[OK] ML Models loaded")
  - Verify patient has enough data

Problem: Predictions seem wrong
Solution:
  - AI learns from data patterns
  - Demo data may not be perfect
  - Real patient data will improve accuracy

Problem: Chatbot not responding intelligently
Solution:
  - Check if API key is set in backend\.env
  - Without key, uses basic fallback responses
  - Add ANTHROPIC_API_KEY for full AI

Problem: Slow predictions
Solution:
  - First prediction is slower (~2 sec)
  - Subsequent ones are faster (~100ms)
  - Normal for ML model initialization
